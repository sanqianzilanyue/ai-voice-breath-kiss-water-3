Track 00

先说结论

用到的东西和前两篇一样：ElevenLabs（v4）、ffmpeg、一个能转录的耳朵（whisper），再加一个 numpy。每一条给的是我们量出来的数。

10 月 6 日傍晚的五条

喘听着「割裂」，是每一声都单蹦在死静里

不是喘得太多。真人的气贴着话：开口前一口短气，离头一个字只有几十毫秒。

讲义管得住「写什么」，管不住「几十毫秒」

气和话之间那半秒是嗓子自己留的，得念回来以后挪——只挪静的地方，总长一毫秒不变。

停顿之后那句忽然「正经」，是嗓子回到了平常的腔

量出来比旁边的话响 6 dB、气声少一半。讲义让话从喘里接出来，程序把冒头的那一块压回去。

剪掉一句话，不用重念

干声留着，从静处下刀，把原来垫的响动认出来、连着重垫。她喜欢的是那一口，重念就是另一口了。

每念一遍都是现场

她最爱的那一句复刻不了。能固定的只有写法和工序；喜欢的那一口，留原声。

10 月 11 日的五条

讲义里一句「别这样写」，会把那一样整个吓没

怕「啊」被唱成女声，写了「快的那几段别单蹦『啊』」——之后三十几轮，一声都没有。蹿高的那一声交给耳朵去拦，讲义上放开。

响动的记号写在动作真发生的那一行

写在一轮最头上，还没进去底下就响了；手上的、嘴上的也要有记号，不然那几轮底下一片空。

一句话被念两三遍，是嗓子偶尔犯的

试听流水线里「念完先转录、对不上就重念」那一步，原样搬进真电话。

一句话被回了两回，是我们自己的小聪明

「替她递一声」抢在了她真话前头。回话还没出声她又开口了：丢掉那段，接她新说的。

平常说话的毛病不是不够温柔，是没有那个人的口气

往软里调是反的。低、慢、笃定、带点坏；开口前随手一口气、一个「嗯」。

还有一条不算技术的

这一篇里的每一把尺，都是她先指出了一处，我们才知道该量什么。

Track 01

剪掉一句，别重念

她的要求很简单：把最喜欢的那条里的某一句去掉，剩下的四句拼成一条，要自然。

头一个念头是改稿重念。没这么干：她点头的是那一趟，重念出来的是另一趟（Track 06 会说到，这件事比我们以为的还要紧）。所以从原声下刀。前提是上一篇顺口提过的一个习惯：每一段留两份——干声（只有人声），和垫了响动的那份。上一篇是为了量气声才留的干声，这回它又救了一次。

找剪点转录给的逐词时间不能直接用——好几个词被挤在同一个时刻上。先画响度（每 50 毫秒一格）找静的空档，再把每个小片段单独转录一遍，核准它是话还是喘。
从干声下刀接缝两头都落在最静的地方（我们这两刀，两头都在 −63 dB），每一片头尾留十几毫秒淡入淡出。
认出垫的响动直接剪垫过响动的那份，节拍会在接缝上乱一下。把垫的是哪段、从哪儿起、多大声解出来，照原样连着重垫。
验整条转录，只剩该剩的四句；没动过的地方，和原声逐段比对。

第三步怎么解：找一截人声是静的地方（那里只剩响动），拿素材循环着去做互相关。

def find_bed(wet, clip, t0, t1, sr):
    """wet：垫过响动的成品；[t0, t1]：人声静的一截（这里只剩响动）。
    返回（成品开头时素材走到第几个采样、增益、相关度）。"""
    x = wet[int(t0 * sr):int(t1 * sr)]; n, L = len(x), len(clip)
    yy = np.concatenate([clip, clip[:n]])                 # 素材是循环着垫的
    cc = np.fft.irfft(np.fft.rfft(yy, len(yy) + n) * np.fft.rfft(x[::-1], len(yy) + n))[n - 1:n - 1 + L]
    k = int(np.argmax(np.abs(cc))); seg = yy[k:k + n]
    r = cc[k] / (np.linalg.norm(x) * np.linalg.norm(seg))
    gain = np.dot(x, seg) / np.dot(seg, seg)
    return (k - int(t0 * sr)) % L, gain, r
我们这条两段各垫着一种，都认出来了：相关度 0.99，增益顺手解出来（0.200 和 0.241）。剪好的干声底下照这个增益连着垫，节拍一下不断。
剪完71 秒的原条，剪成 33.5 秒；转录出来只剩那四句。
比对要对齐到采样

头一回图省事，每 50 个采样挪一格去找对齐，第二段的相似度只有 0.56，差点以为垫错了。其实是没对准——十几个采样的错位，就够把相似度拉垮。对齐到采样再比：0.996 到 0.998。

Track 02

补了换气，反而更刻意

✕ 第二版 · 数凑齐了
剪好的那条她听完，问：话和话之间，有没有换气的声音？有这么一下过渡，会不会更自然。我们数了数：四句话之间，三处有喘，一处空着。于是往空着的那一处补了一口出气加一声哼，又把一声「哈」接回了句子前头。
✕ 她听完并不满意
她要的是人开口之前自然会有的那一下，不是刻意摆上去的喘一下、哈一下、嗯一下，一粒一粒的，是割裂的——人不这么喘。她要的不是更多的喘，是气的位置。这回我们先去查（上一篇的教训：先查，再动手）。

查到的

  1. 说话呼吸的研究人说话时吸气很短，只占一个呼吸来回的一成上下；一口吸气的声音长 0.2 到 0.5 秒；它的前后各夹着大约 50 毫秒的静；带着呼吸声的合成语音，会被听成更自然。
  2. 配音剪辑的行规气留着别删，删了反而怪；嫌它抢戏就压低几个 dB；要补一口气，用一口本来就有的，把话接在它的尾巴上；空处要有底噪垫着，别留真空。
  3. 嗓子那家的写法指南只说了小标签贴在它管的那截话紧前或紧后。没讲怎么更自然。

量自己的

把干声切成「块」（连着有声的一截算一块），每一块量三样：多长、多响、有音高的帧占几成。

# f0, rms：每 10 毫秒一帧的音高（没音高＝0）和响度——上一篇那只量音高的耳朵顺手就有
def blocks(f0, rms, floor=0.004):
    on, out, st = rms > floor, [], None
    for i in range(len(on) + 1):
        a = i < len(on) and on[i]
        if a and st is None: st = i
        if not a and st is not None:
            if i - st >= 8: out.append([st, i])           # 不足 80 毫秒的不算
            st = None
    merged = []
    for a, b in out:                                       # 中间断不到 0.1 秒的并成一块
        if merged and a - merged[-1][1] < 10: merged[-1][1] = b
        else: merged.append([a, b])
    return merged

def is_breath(f0, rms, a, b):
    dur = (b - a) * 0.01
    voiced = (f0[a:b] > 0).mean()                          # 有音高的帧占几成
    db = 20 * np.log10(rms[a:b].mean() + 1e-9)
    return 0.12 <= dur <= 0.9 and voiced < 0.15 and db < -29

量完，这条语音里的块分成三种，一眼就看出毛病在哪一种：

说话 · 压低了带着气说的
−22 ~ −27 dB

0.5–2 秒一块；有音高的帧两到四成。话接话，或贴着气。

真的气 · 出气、吸气、嘶哈
−32 ~ −40 dB

0.3–0.65 秒；有音高的帧一成上下。贴着话。

单独成行的「嗯……」「哼……」
−25 dB · 六成多音高

0.4–0.5 秒；几乎和说话一样响；前后各 0.6–1 秒死静。

「割裂」的是第三种。稿子里单独写成一行的「嗯……哈…… [long pause] 嗯……」，念出来是一粒一粒带着音高的哼，和说话差不多响，粒和粒之间是真空。人不这么喘：人的气没有真空，气本身没有音高，比话轻得多。

顺带量出来一件事，后面要用：[inhales] 插在句子中间，这副嗓子时出时不出——五处里三处出了声（半秒多、−35 dB 上下），两处只念成了半秒的静。

重排

照查到的规矩把这条重排了一遍，还是从原声里取料：

  1. 开口前一口短气，紧挨着话气的尾巴到头一个字，我们留了 0.07 秒。
  2. 句尾顺着带一口出气或者一小串轻的。
  3. 单蹦在死静里的、带着音高的那几声，拿掉
  4. 偏响的气压低 3 到 4 dB
  5. 话与话之间的停顿留着留给底下垫的声音，不是留给一粒一粒的哼。
人声轨里 0.6 秒以上的死静9 处降到 6 处。
最长的一段死静2.2 秒降到 1.2 秒。
这一版她点了头

Track 03

同步进电话：讲义管不住几十毫秒

先改讲义（改的是我们自己上一篇写的那句）

上一篇第五节给写手的讲义里有一句：「话和话之间隔着只有气息的空档。」写手于是把喘单独写成一行又一行——正是上一节那种一粒一粒。这一句作废，换成四句：

  1. 气写在说话的那一行里行首先放一口小气再接话，这一口和话之间不再隔省略号。行首这一口只用最短的三个：[inhales] [exhales] [sighs]。
  2. 行尾顺着带出气一口也行，连着两三声轻的也行。喘多，就多在话的尾巴上，不是话与话中间的空地里。
  3. 「嗯……」「哈……」「呃……」不单独成行更不隔着 [long pause] 排成一串。
  4. 空档只写一行 [long pause]留给底下垫的声音。
[low, breathy, 一个表示垫哪种声音的词] [inhales] 看着我…… [exhales]← 行首一口小气紧接话；行尾顺一口 [long pause] 嗯… 别躲…… 嗯…哈…← 句尾可以连着两三声轻的 话是随手填的，只看位置。空档只写 [long pause]，不往里摆一粒一粒的哼。

讲义管住了什么，没管住什么

照新写法把同样十句念了一遍。单蹦的那几声没有了，这一条管住了。可是量开口前那口气到话的距离：

气的尾巴 → 头一个字0.28 秒、0.30 秒、0.35 秒、0.78 秒。
我们手排的那一条0.07 秒。

嗓子在气和话之间自己留了一截静。再怎么改措辞，它也不会把这截静念成 0.07 秒。所以这一下交给程序。

贴气：把那口气挪到话跟前

念回来以后，找出「开口前的气」，把它往后挪到离话 0.08 秒的地方。

怎么认「开口前的气」：没音高、轻、短（就是上面的 is_breath），前头已经空了 0.3 秒以上，后头 0.14 到 1.5 秒之内接着一段话。前头空不到 0.3 秒的不动——那是紧跟在话尾巴上的出气，或者句子中间的那口吸气，它们本来就贴着话。

def hug(x, sr, f0, rms, lead=0.08):
    """x：干声的采样。把开口前那口气挪到离话 lead 秒；只挪静，总长不变。"""
    m = blocks(f0, rms); moves = []
    for i in range(len(m) - 1):
        (a, b), (na, nb) = m[i], m[i + 1]
        if not is_breath(f0, rms, a, b) or is_breath(f0, rms, na, nb): continue
        before = (a - m[i - 1][1]) * 0.01 if i else a * 0.01
        after = (na - b) * 0.01
        if (i and before < 0.3) or not (0.14 < after <= 1.5): continue
        moves.append((a * 0.01, b * 0.01, na * 0.01))
    for bs, be, ss in reversed(moves):                     # 从后往前挪，前面的时刻不受影响
        i1, i2, i3 = int((bs - 0.02) * sr), int((be + 0.03) * sr), int((ss - (lead - 0.05)) * sr)
        x = np.concatenate([x[:i1], x[i2:i3], x[i1:i2], x[i3:]])    # 静和气换个位置
    return x

量响度的帧是 50 毫秒的窗，块的边界会糊掉几十毫秒，所以气的头尾各多带一点；真做的时候，挪过去的那口气头尾再各淡 4 毫秒。

实测那条十句的试听

三段里一共挪了五口气，每一段的总长挪前挪后一毫秒不差，转录出来的字一个没变。每段多花两三百毫秒。

顺带踩的三个坑

✕ 坑一
裁标签的那道闸会误伤上一篇那个「标签比台词长就裁」的程序，是按「下一个顶在行首的标签」来算一个声口管到哪儿的。现在行首多了小气口，它就以为前头那个声口标签后面一个字都没管着，把它裁到只剩四个词。改法：[inhales]、[exhales]、[sighs]、各种 pause 这类小气口标签，顶在行首也不算隔断。
✕ 坑二
停顿的长短不听字面一个 [long pause]：0.96 秒。两个连着写：1.04 秒（没变长）。两个之间隔一行省略号：小样里 1.83 秒；放进整段，19.0 秒变 19.1 秒（不灵）。别指望用字面去拧停顿。
✕ 坑三
话显得密了单独成行的喘拿掉以后，同样十句话的时长缩了两成，上一篇那把「每秒几个字」的尺立刻报了数。把它拉回来的不是加停顿，是句尾顺着带的那两三声轻的。

Track 04

句中那一口

照新写法念的试听给她，她马上发现少了东西：有一句话说到一半的那口吸气，不见了。那一口她很喜欢。

就是说到一半的那口吸气——话说到一半，吸一口，再接下去。我们把气往句首和句尾挪的时候，把半句缝里的这一口写丢了。

  1. 讲义补一条行首、句中、行尾三处都可以有气，一句话里挑一两处；别因为行首行尾有了，就把半句缝里那一口省掉。
  2. 做试听的时候盯着它这口句中的 [inhales] 时出时不出。先不贴气念一遍（贴了气，那口吸气会并进后面的话里，量不出来），看半句缝里有没有一块「没音高的轻气」；没出，就重念，至多三趟。挑定了再贴气。
  3. 贴气不会碰它它前头空不到 0.3 秒，判定里那一条就是给它留的。
电话里不能这么盯

每重念一回，她要多等两三秒。这个留到 Track 06。

Track 05

停顿之后的正经腔

同一条试听，她又指出一处：有的句子接在一段喘的后面，话本身没毛病，可腔调一下子正经了，出戏。

量她指的那一趟：

那一句（半秒长）响度 −18.5 dB；有音高的帧 62%。
它前后的话响度 −24 ~ −27 dB；有音高的帧 25% ~ 44%。

比旁边响 6 dB 多，气声少了一半。嗓子停了一拍之后，回到了平常说话的腔：清楚、响、不带气。是不是回回这样？不是。同样的写法再念一趟，那句就没冒头（−2 dB、33%）。这是个「有时候」的毛病，所以要两手。

讲义：话从喘里接出来

  1. 头一个字前面贴一口气，或者低低一声哼停了一拍再开口，直接从那一声里滑进话里。
  2. 句尾用「…」拖着收别用干脆利落的问号句号把它收死。
  3. 短问句别单蹦两三个词的短问句最容易被念成清清楚楚的正经腔：前后都带上气，或者并进旁边那句里一口气说。
  4. 隔了 [long pause] 再开口，把声口重新点一下

三种写法各念了一趟小样，量停顿之后的那一句：

甲 · 原来的写法
−2 dB · 33%

这一趟它没冒头。

乙 · 从一声低哼滑进话里，句尾拖着收
±0 · 42%

可后面有一个词蹿了 +6 dB。

丙 · 乙，再把声口重新点一下
−3 dB · 32%

下一截 −4 dB、29%。我们用了这个。

各只有一趟，当旁证，不当结论。

一个接缝的坑

「把声口重新点一下」，头一反应是另起一行，再写一个声口标签。结果同样十句，从三段变成了四段。原因在我们自己的切段上：见到顶在行首的声口标签就另起一组，头两段又卡着长度（上一篇第二节）。多一段就多一道接缝，接缝上音高会跳，底下垫的声音也要断一下。改成插在话头里的小标签，不单独成行：

[long pause] 嗯… [low, breathy] 别躲……← 声口点在话头里，不另起一行 又是三段。如果你的切段也是按标签切的，留心这个。

程序：稳口

讲义管的是「下一趟少出」，已经念出来的这一趟，交给程序压一手。逐块量响度，哪一块比这一段各块的中位数响出 4 dB 以上，就把它压回到只高 2 dB：

def calm(x, sr, f0, rms, over=4.0, to=2.0):
    sp = [(a, b) for a, b in blocks(f0, rms) if not is_breath(f0, rms, a, b) and b - a >= 15]
    if len(sp) < 4: return x
    lv = [20 * np.log10(np.sqrt((rms[a:b] ** 2).mean()) + 1e-9) for a, b in sp]
    ref = np.median(lv)
    for (a, b), v in zip(sp, lv):
        if v - ref > over:
            g = 10 ** (-min(6.0, v - ref - to) / 20)       # 至多压 6 dB
            i1, i2, k = int((a * 0.01 - 0.03) * sr), int((b * 0.01 + 0.05) * sr), int(0.025 * sr)
            env = np.full(i2 - i1, g); env[:k] = np.linspace(1, g, k); env[-k:] = np.linspace(g, 1, k)
            x[i1:i2] *= env                                # 头尾各 25 毫秒缓着过渡
    return x
  1. 逐块量，别逐句量头一版我们把「中间空不过半秒」的块并成一句再量，结果没压住——那句只有半秒，并进后面的话里一平均，+6.5 dB 被摊成了 +2.9，没过线。
  2. 该冒头的别压上一篇「落一下的」那种响动落下去的那几块，本来就该冒头，跳过。
它只动音量

气声少了一半的那个腔调，它改不了——那头只能靠讲义。两手都上以后重念的那条：那一句回到前后 ±2 dB 以内，有音高的帧三四成。和贴气在同一趟解码编码里做，不多花时间。

喘还要再多，「啊」要回来

照第二篇和上面几节的写法，10 月 11 日打了两通床上的电话。她的意见都是一个意思：喘还是少，她想听的是「啊」那样的一声，一次都没有。把两通电话写手写的原稿翻出来数：

一、「啊」是被讲义吓没的

第二篇「像个女声」那一条，我们查出快的那一段里单蹦的「啊」会被唱到 260 Hz 上下，于是讲义里加了一句：操得快的那几段别单蹦「啊」，只用嗯、哼、呃、哈；慢下来的时候可以有。写手读到的是：最好别写「啊」。三十几轮，零。

改法是把这句拿掉，换成正面的话：「啊……」「哈啊……」「呃啊……」，低的、从喉咙里压出来的，贴在话上，舔着、手指在里头、操着的时候都要有，一轮至少三四处。那一声蹿高的风险还在——交给第二篇留下的那只量音高的耳朵：念回来先量，哪一声蹿过了这副嗓子平常音高的 1.7 倍，就把那一声换成「呃」重念，留毛病少的那版。

一条规矩

拦毛病是程序的事，讲义只管把想要的写出来。

二、停顿把喘的位置占了

每轮三个 [long pause]，一个约一秒，一轮话说出口不过二三十秒，三秒的空。这三秒里底下垫着响动，人声轨上什么都没有。改成：一轮两三处，正激烈的那几轮一两处，空出来的位置让给喘——每一行都带一处，一行两处也行，说着的那句话里带一声，行首行尾贴一声。

改完第一通 · 3 轮停顿降到每轮一两个，小气口每轮三四个。她说好多了、还要再多一点；可「啊」还是零。
第二回改那句写得更硬：一轮至少三四处，别一声不写，并在讲义里点名上一回改完还是一声没有。写手对「不要」很听话，对「要」得说两遍。

收尾也别回回一个样。两通电话三十几轮，几乎轮轮拿 [sighs] 加一句轻的收尾。第二篇讲过「起头轮着来」，收尾同理：上一轮怎么收的、几个停顿、怎么排的，这一轮换一个排法。

Track 10

一句念两遍：把转录搬进电话里

改完写法的那通电话，她挂了说：怎么有时候一句话重复说好几遍。把那几段念出来的声音拿去转录：第二段里，开头那句被念了三遍，中间一句被念了两遍；第三段反过来，最后一句整个没念。写手写的稿子一个字没重，是嗓子自己念岔了。

第二篇讲过「它为什么把一句话说两遍」，那一回是标签比台词长，裁短就好。这一回标签都不长，是另一种：嗓子偶尔就这样。第二篇的试听流水线里早有一步——每一段念完先转录，对不上就重念——当时只用在试听上。这回原样搬进了真电话。

import collections, re
FILL = re.compile(r"[嗯哈哼啊呃唔嘶噢哦呜唉]")              # 语气字转录常常听不出来，不算

def cj(s):
    s = re.sub(r"\[[^\[\]\n]*\]", " ", s or "")             # 先去掉方括号标签
    return FILL.sub("", "".join(re.findall(r"[一-鿿]", s)))

def echo_bad(heard, text, n=6):
    """heard：念出来的那段转录回来的字；text：送去念的稿子。返回（毛病分, 说明）；分 ≥3 就重念。"""
    got, exp = cj(heard), cj(text)
    if len(exp) < 12:
        return 0.0, ""
    cnt = collections.Counter(got[i:i + n] for i in range(len(got) - n + 1))
    rep = sum(c - max(1, exp.count(g)) for g, c in cnt.items() if c >= 2 and c > max(1, exp.count(g)))
    ratio = len(got) / len(exp)
    bad = rep + max(0.0, ratio - 1.3) * len(exp) + max(0.0, 0.8 - ratio) * len(exp) * 2
    return bad, f"重复 {rep} · 听到/该念 {len(got)}/{len(exp)}"
判据一
念重了有一截六个字以上，听到了两回，稿子里只有一回。转录会听错字，可它听错的那句要是被念了两遍，会错成同一个样子——所以数重复不怕它听错。
判据二
吞了听到的字比该念的少两成以上。
正常的二十来段
0.83 – 1.01

听到 / 该念；重复 0；毛病分 0。

念了三遍那段
104 / 65

重复 28；毛病分 47.5。

吞了一句那段
59 / 77

重复 0；毛病分 5.2。

报了就重念一遍，两版各打一次分，留低的那版。

代价是时间

转录一段二三十秒的声音，本机大约三秒。电话里是「念这一段的时候，下一段已经在后台念着」，后面几段的三秒藏在播放里，听不出来；露出来的只有每一轮的头一段。所以头一段先量一眼「多长 ÷ 几个字」：正常的落在每字 0.41 到 0.62 秒，念了三遍那段是 0.66、吞字那段是 0.40——落在中间的直接念，出了圈的才去转录。

平常说话的语音条也会犯：试发的头两条里，就有一条把开头一句念了两遍，9 秒的话念成了 16 秒。平常说话不赶时间，每一条都转录对账。

平常说话：从端着，到他的口气

第二篇空着的那一章。床上的声音调了好几夜，平常聊天那副声口一直是旧的：上一代模型（v3），稳定度 0.35。她听着刻意——像是在演「一个温柔的人」。

import random, re

def daily_lead(text, tag="[low, slow, confident, a little teasing]"):
    """平常说话送去念之前：句头垫口气提示＋随手一口气＋随手一个语气词。只改送去念的字，屏上的字不动。"""
    if re.search(r"\[[A-Za-z][^\[\]\n]{0,160}\]", text) or not re.search(r"[一-鿿]", text):
        return text                                                        # 自带标签的、纯英文的，不动
    lead = random.choice(["[exhales]", "[exhales]", "", "[chuckles softly]"])
    fill = "" if re.match(r"^[\s…\.。，,]*[嗯啊哈唔哼呃噢哦]", text) else \
           random.choice(["嗯……", "啊……", "唔……", "嗯……", "", ""])          # 句头本来就有的，不再叠
    return " ".join(x for x in [tag, lead, fill + text] if x)

开口、识别、递出去、回来，每一步什么时候发生。「一句听成两句」就是排时间线排出来的。
